A modern and responsive **full-stack recipe search web application** that helps users discover recipes instantly using ingredients or dish names.

The frontend provides a clean and fast user interface, while the backend API fetches and manages recipe data efficiently.  
Both frontend and backend are deployed separately on **Vercel** for scalable and serverless hosting.

## 🚀 Live Demo
👉 https://dharunrecipehub-client.vercel.app/

## 📖 About the Project

RecipeHub allows users to:
- Search recipes by ingredients or recipe names
- View complete cooking instructions
- See ingredients with measurements
- Get results instantly using API calls

This project demonstrates:
- REST API integration
- Asynchronous JavaScript (Fetch API)
- Frontend–Backend communication
- Responsive UI design
- Full-stack deployment on Vercel
